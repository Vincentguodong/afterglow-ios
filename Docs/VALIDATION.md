# 验证范围

版本：1.1.0 / build 2。

**当前公开版本尚未完成 Xcode 编译、Apple SDK 类型检查、XCTest 执行、签名或真机运行。**不要把源代码语法检查或界面设计当作安装与运行成功的证明。

## 本地静态检查

```bash
python3 Scripts/check_source.py
```

该脚本检查 plist、Asset Catalog JSON、共享 scheme XML、Xcode 工程引用等配置；如果已安装 `tree-sitter` 与 `tree-sitter-swift`，还会解析 Swift 语法。`--write-report` 可生成本地机器记录。

这些检查不能验证 Apple SDK 的类型、相机硬件行为、运行时权限、性能或数据恢复。

## 已编写、尚未执行的 XCTest

1. 配方序列化与边界。
2. 六款胶片保持图像尺寸。
3. 曝光改变实际像素。
4. 原片持久化、重载和删除。
5. 损坏索引不被覆盖。
6. 草稿恢复与旧草稿编辑不得覆盖新草稿。
7. 缺失缩略图时仍可删除成片和原片。
8. 拍摄裁切符合取景比例。
9. 分享原片保留 PNG 字节与扩展名。
10. 未写入索引的照片文件保留以供恢复。

在 Mac 和已安装的 iOS 模拟器上运行：

```bash
bash Scripts/test.sh
```

需要更换模拟器时，设置 `SIMULATOR_DESTINATION` 环境变量。
